# config 目录说明

## 两个文件的作用和区别

### config.yaml
- **存放配置数据**：应用名、端口、数据库连接信息等
- **纯文本文件**，YAML 格式，人可以直接读写
- **改动不需要重新编译**：修改配置后重启程序即可生效
- 相当于"写好的参数表"

### config.go
- **读取配置数据的代码**：用 Go 代码把 config.yaml 里的内容加载到内存
- **源文件**，会被编译进程序
- **改了需要重新编译**才能生效
- 相当于"取参数的动作"

### 总结
| 文件 | 存什么 | 改了之后 |
|------|--------|----------|
| config.yaml | 配置值（端口、密码等） | 重启程序即可 |
| config.go | 读取配置的逻辑代码 | 需要重新编译 |
